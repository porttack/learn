## Students will be able to

- Explain that computers store letters, digits, and punctuation as numbers.
- Decode and encode messages with the ASCII table.
- Notice that capital and lowercase letters have different codes.

## Before class

- Print one [worksheet]({{ '/unplugged/ascii-messages/' | relative_url }}) per student.
- Print keep-going sheets from the [New set page]({{ '/unplugged/ascii-messages-generator/' | relative_url }}):
  Copies = class size, Sets per student = 2 (front and back).

## The lesson

### 1. Hook (5 minutes)

Write **72 73** on the board. Ask: *"If computers can only store numbers,
how do they store this text message?"* Reveal that 72 73 spells **HI**.

### 2. The sheet (20 minutes)

Students decode the first messages with the code table, then move on to
lowercase, punctuation, and digits, then write their name in ASCII.

### 3. Secret messages for a friend (10 minutes)

Students write coded messages for a partner, swap, and decode. Keep it
friendly: anything they write, the receiver will read out loud.

### 4. Keep going (as students finish)

Hand out keep-going sheets so neighbors get different messages.

### 5. Wrap-up (5 minutes)

Ask: *"Why does 'A' have a different number from 'a'?"* (They're different
characters, so they need different codes. A computer can't guess which you meant.)

## Going further

- [Count the Dots]({{ '/unplugged/count-the-dots/' | relative_url }}) first,
  if students haven't seen binary yet.
- [Secret Messages in Binary]({{ '/unplugged/ascii-messages-binary/' | relative_url }})

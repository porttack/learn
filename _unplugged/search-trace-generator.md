A fresh sorted list and target every time you click **New set**. Trace it
the same way as [Trace a Search]({{ '/unplugged/search-trace/' | relative_url }}):
mark each box linear search checks, left to right, then mark each box
binary search checks, starting in the middle. The set number prints on the
sheet. To get the same list back later, type its number into the
**Set #** box.

The **List** option has an "unsorted" choice. Try it once you've traced a
few sorted lists: the same binary search steps (start in the middle, go
left or right) stop working when the list isn't in order. Watch for where
it goes wrong.

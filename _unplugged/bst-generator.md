A fresh tree every time you click **New set**: pick **Search a tree** for
more practice tracing searches, or **Build a tree** for a new pair of
insertion orders to build by hand. Size picks the range the numbers come
from; **Build a tree** always uses seven of them, however big the range.
The set number prints on the sheet. To reprint the same set later, type
its number back into the **Set #** box.

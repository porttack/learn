A fresh rhyme to decode every time you click **New set**, boxed the same
way as the main worksheet. "One rhyme" is one short poem; "Two rhymes"
strings two together for more practice. The set number prints on the
sheet. To reprint the same set later, type its number back into the
**Set #** box.

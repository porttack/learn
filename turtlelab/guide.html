TurtleLab guide

For students and teachers. TurtleLab works in Chrome, with a mouse or a touchscreen.

Your first minute

  1. Tap a round button on the left to open a palette of blocks. Try the green turtle.
  2. Drag a block out onto the page. Drag a second block just under the first. You will see a ring where it will snap.
  3. Tap any block to run its whole stack. The turtle moves and draws.
  4. Tap a number on a block to change it, then press Enter.

To use the Run button, open the Flow palette and drag out a start block, then snap your blocks under it. Run begins at the start block. If there is no start block, Run uses the top stack on the page.

Try a sample

Not sure what to build? The samples page has programs to open, from a plain square up to a turtle that wanders by chance. Each one runs by itself, so you can watch it draw, and has a sticky note that explains it. Change the blocks and see what happens. Nothing you change is saved unless you press Save, and the blocks you saved before are never touched.

Want a path to follow? TurtleLab Lessons has five steps, from drawing your initials to a piece of art of your own, each starting from a sample.

Make your own blocks

When you keep building the same thing, make it a block. Open My Blocks and drag out the to block. Tap the first box and type a name, like square. Put the blocks you want under it. That is what your block does.

Your new block shows up in My Blocks, ready to use. Drag it under a Start block, and when the program gets there, the blocks under to run.

Want it to work for different sizes? Tap the dashed input box and type a name, like size. Your block now has a place to type a number, and a size block appears in My Blocks. Plug it in wherever the number belongs, like the one in forward. A block can have two inputs.

A block can even use itself, which is how a spiral or a tree gets drawn. Give it a way to stop, like an if, or it will keep going until TurtleLab stops it for you. A stop block inside one of your blocks only leaves that block.

Change a name and every use of the block changes with it. Delete the to block and the blocks that use it will say they cannot find it. Undo brings it back.

Saving your work

TurtleLab keeps your blocks for you. If you refresh the page, they are still here when it comes back. That copy stays in this browser, on this computer, and nowhere else.

  • Save (the arrow button, or Ctrl+S) downloads a picture of your drawing. Your blocks are tucked inside it. It is a normal PNG, so you can put it in a document or share it like any other picture.
  • PDF (the button with PDF on it) downloads a one page PDF to hand in: your blocks in the top half, laid out the way they are on your screen, and your drawing in the bottom half, with the turtle where it stopped so a teacher can see which way it is facing. The picture with your blocks inside is attached to it, and that picture is just the drawing, with no turtle.
  • Open (the folder button), or dragging a saved picture or a PDF onto the page, brings your blocks back, and the drawing too. A PDF has to be one that TurtleLab saved. Undo takes you back to the blocks you had before.
  • New (the page with a plus) starts over with no blocks and clean paper. If you press it by mistake, Undo brings your blocks back.

On a shared computer, press New when you are finished, so the next person does not start with your blocks.

Only your blocks, and the words on any notes you wrote, are saved inside the picture. It has no name, no date and nothing about the computer you used. Read your notes before you share a picture, because anyone who opens it can read them.

See your blocks as Python

Press the Python button (the three arrows, like the prompt in Python) and a small box shows your blocks written as Python. It uses the turtle module that comes with Python, so you can press Copy, paste it into IDLE or Thonny, and run it. It is also written to work in EduBlocks (edublocks.org). The box changes as you build, so you can watch the Python appear one block at a time.

Blocks you make become def functions, your inputs become parameters, boxes become variables, and notes become comments. The two do not match everywhere. Python's turtle counts angles from the east and turns the other way, so a few lines look different from the blocks, such as setheading(90 - 30). The Python is meant for reading and learning. Press the button again to hide the box.

Things to know

  • The paper is 700 wide and 560 tall. The middle is 0, 0. The turtle starts there, facing up. Turning right makes the heading go up: 90 is right, 180 is down, 270 is left.
  • Colors are red, green and blue, each from 0 to 255. Black is 0, 0, 0. White is 255, 255, 255. A gray has the same number three times.
  • Boxes hold a number, and there are four of them. Use store in box1 to put a number in, and the box1 block to use it. Every time you run a program the boxes start at 0.
  • Math blocks read left to right, like a sum on paper. Put one block inside another to say what is worked out first.
  • print shows its number in the Output box at the top right.
  • wait counts tenths of a second, so 10 is one second.
  • Stop always works, even in a forever loop.
  • Sticky notes are for explaining what you are doing, to yourself and to anyone who reads your program. Drag one out of the Notes palette and tap it to write. A note never changes how your program runs, and it does not snap to other blocks, so put it wherever it helps.

When something goes wrong

If a block has a problem, the program stops, the block gets a red outline, and a message under the drawing says what happened. For example, an if block (or an if with an else) with nothing plugged into it will ask for a yes or no block, like a less than block.

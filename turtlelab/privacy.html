TurtleLab privacy

Effective date: November 3, 2026

The short version: TurtleLab does not collect, keep, or send anything about you. There are no accounts, no cookies, no analytics, no advertising, and no server of its own. Everything you do happens inside your browser tab, on your own device.

Facts for IT staff

QuestionAnswer
Does it have a backend or server of its own?No. It is a folder of ordinary files (web pages, scripts, styles, fonts and pictures) that GitHub Pages hands to the browser. Your browser runs them. Nothing runs on a server.
Are accounts or sign-in needed?No. There is nowhere to type a name, an email address or a password.
Does it set cookies?No.
Does it use analytics, trackers or ads?No.
Does it load anything from another website?No. The scripts, fonts, icons and styles all come from the same address as the page. There are no content delivery networks and no outside fonts.
Does the page send anything anywhere while it runs?No. The code contains no network requests, no forms, and no way to upload data. The browser would also refuse them (see the policy below).
Does it keep anything on the device?Not at the moment. Your blocks and drawing exist only while the tab is open. When a save feature is added, it will only write files that you choose to download, and any automatic backup will stay in your own browser's local storage on your device. It will never be sent anywhere. This page will be updated first if that changes.
Can it be checked?Yes, easily. See below.

The browser enforces it

Every TurtleLab page carries a Content Security Policy. This is an instruction the browser itself follows, and it means the page is not allowed to load or contact anything outside its own address, even if a mistake were made in the code:

default-src 'self'; img-src 'self' data: blob:; font-src 'self'; style-src 'self'; script-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'

In plain words: scripts, styles, fonts and requests may only come from this site; forms may not send anywhere; and nothing can be embedded from outside.

How to check for yourself

  • Open the browser's developer tools (F12) and look at the Network tab while using TurtleLab. You will only see the page's own files loading, once, and then nothing more.
  • Look at the Application tab: there are no cookies, and local storage is empty.
  • Use View Source. There is no hidden code. The whole program is public.

Hosting

The site is hosted by GitHub through GitHub Pages. Like any web host, GitHub's own systems handle basic connection details (such as an IP address and which page was asked for) to deliver the files. That is part of how GitHub runs its service, and it is not something TurtleLab collects or can see. It is described in GitHub's own Privacy Statement.

Student records

Because TurtleLab collects nothing, it creates no student records of any kind. The wider statement for the whole learning site, including a section on FERPA, is at learn.porttack.com/privacy.

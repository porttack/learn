{% comment %} "For a sub" box at the top of every CS Unplugged lesson plan. Prints (it's meant to be left on the desk), unlike the screen-only teacher box. One copy of the wording so every plan says the same thing. Parameters: sheet worksheet URL say what the sub reads aloud (one or two sentences) keep_going what the keep-going sheets are, e.g. "message-in-lights puzzle" generator New set page URL setup optional: what to say instead of "Nothing to set up" note optional: one extra instruction (e.g. a section to skip) slides optional: slide deck path; adds a projector note with the address spelled out, since this box is read on paper slides_stop with slides: title of the slide to stop on before handing out sheets (later slides are meant for after the sheet) go optional: short-link word (go/.md); the box then prints learn.porttack.com/go/ instead of the long address class_size optional: your usual class size (e.g. 30). Links straight to a ready class set (that many copies, 2 per student) instead of making the sub-day prep person set Copies by hand. sheet_note optional: for an activity split across more than one printed sheet. Appears right after "Hand out," and again in the before-the-sub-day printing instructions. sheet_label optional: replaces "worksheet" in "Hand out the worksheet" (e.g. "instructions"), for a first sheet that isn't itself the thing students work on. sheet_no_name optional: true suppresses "Names on top" on the handed-out sheet named by `sheet` (e.g. a reading-only sheet with no name line of its own). Put which sheets DO need a name, and what to collect, in `sheet_note` / `collect`. collect optional: replaces "every sheet, finished or not" in the Collect step, e.g. to name which of several sheets actually need to come back. before_sub_day optional: replaces the whole "Before the sub day" paragraph (including its own bold lead-in) for an activity too particular for the built-in copies/Sets-per-student phrasing, e.g. one printed as several numbered sheets. "Keep going," never "extra" or "early finishers": the next sheet is just the next thing to do, not a bonus or a sign the first one was optional. {% endcomment %}

{% comment %} The engine of a TurtleLab Lessons slide deck. The page defines window.DECK first: { title, backHref, backLabel, slides: [...] } A slide: { kind: "title" | "bullets" | "answer", kicker, title, subtitle, bullets: [string], html, side: true, code, demo: {sample, grid, hint}, notes, down: [slides] } bullets short lines (a string may hold ...), what a student reads html a picture or table, as HTML (below the bullets, or beside them with side: true) demo a live TurtleLab in its slim mode (?embed=1) on the right of the slide, nothing in it is saved notes only in the notes panel and the printable outline, never on the slide down extra slides (answers, detail) reached with the down arrow, skipped by next and previous Same keys as the other decks: arrows, space, N notes, O outline, F fullscreen; ?slide=N&extra=M deep links, ?outline=1. {% endcomment %}

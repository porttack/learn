# _program-notes-public

Teacher planning material that's fine to have in git history and visible to
anyone browsing this repo, but isn't a Jekyll-rendered lesson page. The
underscore prefix means Jekyll ignores this directory by default, same as
`_program-notes/` — the difference between the two is only about git, not
about publishing.

- `_program-notes/` — candid working drafts, gitignored, never committed.
  Write freely here.
- `_program-notes-public/` — the same kind of material, but reviewed and fine
  to check in. Move something here (or write it here directly) once it no
  longer needs the privacy of the gitignored draft.

If something needs to be an actual page students or other teachers see on the
site, it belongs in a pathway directory instead (e.g. `rovrobotics/todo.md`),
not here.

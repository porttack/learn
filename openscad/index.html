Open from GitHub

Paste the address of a file (it opens at once) or of a repository or folder (you can type just owner/repo) (you get a list of its .scad files to pick from). A file opens as a new drawing here; your other drawings are not touched. For a private repository, make a fine-grained token for just that repository with Contents: Read-only. It is sent only to GitHub. This page keeps it in memory while it stays open, so you do not retype it, and never writes it to disk.

Save to GitHub

The token is sent only to GitHub. This page keeps it in memory while it stays open, so you do not retype it, and never writes it to disk: reload or close the page and it is forgotten. Make one at GitHub, Settings, Fine-grained tokens with access to just this repository and Contents: Read and write, and let it expire soon.

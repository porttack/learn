# Standards Reference

The canonical, cross-source standards catalog and reverse map for every
pathway and unit this site (and its sibling sites) cite standards against.
Not sequenced lessons — a lookup reference, generated from
[`_standards/`](https://github.com/porttack/learn/tree/main/_standards) (the
framework catalog) and
[`_standards/carriers/`](https://github.com/porttack/learn/tree/main/_standards/carriers)
(which lesson, chapter, or unit covers which code), by `tools/build_alignment.py`.

## Coverage

[Standards Alignment]({{ '/standards/alignment/' | relative_url }}) — which
source (a book chapter, a unit plan, lab practice) carries which code across
every framework above, and what's still unassigned.

Every code here is an official framework identifier; every description is an
original paraphrase written for this project, never the framework's own text.

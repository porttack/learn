AP Computer Science Principles

#1.4 Identifying and Correcting Errors AP Computer Science Principles

Programs fail in a few recognizable ways, and testing with well-chosen inputs -- including edge cases -- is how those failures get found before a user does.

Covered in Unit 2 (Week 2: Arrays)

Debugging ('Step through', 'Step into'), a named week-2 topic with its own Shorts, is finding and fixing a mistake in a program.

#3.1 Variables and Assignments AP Computer Science Principles

Covered in Unit 1 (Week 1: C), Unit 6 (Week 6: Python)

Variables is a named topic in both C (week 1) and Python (week 6).

#3.10 Lists AP Computer Science Principles

A list holds an ordered sequence of values that a program can step through one at a time.

Covered in Unit 2 (Week 2: Arrays), Unit 5 (Week 5: Data Structures)

Arrays (week 2) and the list-like Abstract Data Types -- Queues, Stacks, Linked Lists (week 5) -- are both named.

#3.12 Calling Procedures AP Computer Science Principles

Calling a function hands control to a separate block of code and, often, gets a value back in return.

Covered in Unit 2 (Week 2: Arrays), Unit 6 (Week 6: Python)

Functions is a named Shorts topic in week 2 and an explicit topic ('Functions, Arguments, Return Values') in week 6.

#3.13 Developing Procedures AP Computer Science Principles

Writing a function well means giving it parameters general enough to be reused, and a name and docstring that explain what it does without exposing how.

Covered in Unit 2 (Week 2: Arrays), Unit 6 (Week 6: Python)

Same functions claim as 3.12 -- writing them, not just calling them.

#3.14 Libraries AP Computer Science Principles

Importing a library brings in code someone else already wrote and tested, so a program can use it without reimplementing it.

Covered in Unit 1 (Week 1: C), Unit 6 (Week 6: Python)

Header Files, Libraries, and Manual Pages (week 1) and Modules, Packages (week 6) are both named topics.

#3.2 Data Abstraction AP Computer Science Principles

Grouping related values under one name lets a program treat a collection as a single thing instead of tracking each part separately.

Covered in Unit 2 (Week 2: Arrays), Unit 5 (Week 5: Data Structures)

Strings and Arrays (week 2) and Abstract Data Types (week 5) are all ways of building a data abstraction on top of a single variable.

#3.3 Mathematical Expressions AP Computer Science Principles

Covered in Unit 1 (Week 1: C)

Operators is a named week-1 topic; Integer Overflow and Floating-Point Imprecision are what happens when a mathematical expression's result doesn't fit its type.

CSTA 2026

#HS-ALG-PS-01 CSTA 2026 (High School)

Solving a problem well often means choosing the right data structure to go with the algorithm, not just writing steps in isolation.

The focus is picking and using structures a language already provides (like a list or a class) to support the plan, not implementing custom structures from scratch -- a leaderboard built on a list plus a sort is the kind of example this covers.

Covered in Unit 5 (Week 5: Data Structures)

Choosing the right data structure -- queue, stack, linked list, tree, hash table -- for a job is the whole week.

#HS-PRO-PD-12 CSTA 2026 (High School)

Splitting a program into distinct, well-organized pieces -- functions, imported libraries, or objects -- makes the result easier to read and easier to reuse.

Straightforward decomposition is the target; elaborate design patterns or deep class hierarchies aren't expected.

Covered in Unit 2 (Week 2: Arrays), Unit 6 (Week 6: Python)

Functions, named in both weeks, are splitting a program into well-organized pieces.

#HS-PRO-PD-13 CSTA 2026 (High School)

Good program development leans on outside resources -- reference docs, existing libraries, simple APIs, and the features built into a development environment -- rather than reinventing everything from scratch.

Using these resources well is the goal, not building new ones.

Covered in Unit 1 (Week 1: C)

Manual Pages, a named week-1 topic, are exactly the reference documentation this standard describes leaning on.

#HS-PRO-VD-16 CSTA 2026 (High School)

Choosing the right structure -- a list, a dictionary -- to hold a program's data is what makes storing, retrieving, and changing that data manageable.

Common built-in structures are the scope here; things like linked lists, trees, and graphs are not.

Covered in Unit 2 (Week 2: Arrays), Unit 5 (Week 5: Data Structures)

Arrays (week 2) and the named data structures (week 5) are choosing the right structure to hold a program's data.

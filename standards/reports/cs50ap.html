AP Computer Science Principles

#2.1 Binary Numbers AP Computer Science Principles

Computers store everything as bits, and binary place-value works the same way decimal place-value does, just base 2 instead of base 10.

Covered in Unit 0 (Week 0: Scratch -- data representation only (unary, binary, decimal, ASCII, Unicode, RGB)), Unit 4 (Week 4: Memory -- data representation only (hexadecimal, images, file I/O))

Unary/binary/decimal/ASCII/Unicode/RGB (week 0) and hexadecimal (week 4) are both explicitly named -- this is DAT-1's own topic, encoding information as sequences of bits.

#2.4 Using Programs with Data AP Computer Science Principles

Programs that read, combine, and rewrite data files let a person do with a data set what would be impractical by hand.

Covered in Unit 7 (Week 7: SQL)

SQL is literally a program for pulling information out of a data set -- Tables, Statements, and Keywords/Functions are named week-7 topics.

#3.11 Binary Search AP Computer Science Principles

Searching a sorted collection by repeatedly cutting the remaining range in half finds a value in far fewer steps than checking every element.

Covered in Unit 3 (Week 3: Algorithms (searching, sorting, asymptotic notation, recursion))

Binary Search is a named subsection of week 3, alongside its own Shorts video.

#3.17 Algorithmic Efficiency AP Computer Science Principles

Algorithms that solve the same problem are not equally fast, and how an algorithm's running time grows with input size is what separates a practical solution from an impractical one.

Covered in Unit 3 (Week 3: Algorithms (searching, sorting, asymptotic notation, recursion))

Asymptotic Notation (O, Ω, Θ) is the week's own explicit framing for algorithmic efficiency.

#3.9 Developing Algorithms AP Computer Science Principles

Building an algorithm from scratch usually means starting with a rough version and refining it in small, testable steps.

Covered in Unit 3 (Week 3: Algorithms (searching, sorting, asymptotic notation, recursion))

Comparing Linear Search against Binary Search, and Bubble/Selection Sort against Merge Sort, is exactly 'compare two or more algorithms to see whether they produce the same outcome.'

#4.1 The Internet AP Computer Science Principles

The internet moves data between computers by breaking it into pieces and routing each piece independently through a shared network of devices.

Covered in Unit 8 (Week 8: HTML, CSS, JavaScript)

Routers, TCP/IP, and DNS are named week-8 topics, with an 'Internet Primer' Short and demo ('Passing TCP/IP Packet').

#5.6 Safe Computing AP Computer Science Principles

Personal data collected online carries real risk, and encryption and authentication are the main tools for limiting who can get at it.

Covered in Unit 7 (Week 7: SQL), Unit 9 (Week 9: Flask)

SQL Injection Attacks are a named week-7 topic (an attack method); Sessions and Cookies (week 9) are the mechanism by which a site collects and holds data about a visitor across requests.

CSTA 2026

#HS-ALG-PS-03 CSTA 2026 (High School)

Comparing two algorithms for the same job means checking more than just whether they work -- how fast they run and how easy they are to read matter too.

Comparisons can be informal or based on test runs rather than a formal proof of running time.

Covered in Unit 3 (Week 3: Algorithms (searching, sorting, asymptotic notation, recursion))

Asymptotic Notation is comparing algorithms by more than whether they're correct.

#HS-DAT-DC-22 CSTA 2026 (High School)

A data dictionary spells out, for every column in a dataset, its name, its type, and the values it's allowed to hold -- plus how columns depend on each other, like a skipped survey question leaving a related answer blank.

Documenting an existing dataset this way is the task; building the dataset, or handling huge or specialized data, is not.

Covered in Unit 7 (Week 7: SQL)

SQL's Types and Constraints, applied per column, are a data dictionary made explicit and enforced by the database itself.

#HS-SYS-NT-34 CSTA 2026 (High School)

A network diagram shows both the physical pieces -- servers, routers, devices -- and the software running on them, and how all of it connects to get work done.

Drawing the diagram is the task, not physically building the network.

Covered in Unit 8 (Week 8: HTML, CSS, JavaScript)

Routers, TCP/IP, and DNS are the named physical/logical pieces a network diagram would show.

#HS-SYS-NT-35 CSTA 2026 (High School)

The internet is really a network stitched together out of many smaller networks, with its own layered structure, hardware like routers, and protocols like TCP/IP tying it together -- which sets it apart from something like a single classroom network.

A high-level, conceptual grasp is the goal, not configuring real equipment or analyzing network traffic.

Covered in Unit 8 (Week 8: HTML, CSS, JavaScript)

The week frames the internet as networks cooperating (Routers, TCP/IP, DNS) rather than one single network.

#HS-SYS-SE-33 CSTA 2026 (High School)

Given a described security weakness, proposing a fix means naming the vulnerability, what could go wrong because of it, and concrete steps -- technical and non-technical -- to close the gap.

Proposing the fix is the task; actually building it is not.

Covered in Unit 7 (Week 7: SQL)

SQL Injection Attacks, paired with its standard defense (parameterized queries), is 'given a weakness, propose a fix.'

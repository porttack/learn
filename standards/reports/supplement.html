AP Computer Science Principles

#1.1 Collaboration AP Computer Science Principles

Working with other people, and giving them credit, changes how a computing project turns out.

Covered, no locator on record

No pair-programming or collaborative-workflow content anywhere in the book. Taught continuously, through lab pair work and the Create Performance Task, not as a standalone lesson.

#3.11 Binary Search AP Computer Science Principles

Searching a sorted collection by repeatedly cutting the remaining range in half finds a value in far fewer steps than checking every element.

Covered, no locator on record

The book teaches linear search explicitly (Chapter 7, named 'linear search' in the text) but never introduces binary search, even conceptually -- no `bisect`, no sorted-list halving example anywhere. Taught in the November algorithms block.

#3.16 Simulations AP Computer Science Principles

A simulation stands in for a real process that would be too slow, risky, or expensive to run for real, trading some realism for repeatability.

Covered, no locator on record

No dedicated simulation content in chapters 1-13; 'simulation' as a word only surfaces in Chapter 19 (independent-study range, not this topic's natural home). Chapter 12's random-number work is adjacent but not the same idea (generating text, not modeling a process). Taught in the November algorithms block.

#3.17 Algorithmic Efficiency AP Computer Science Principles

Algorithms that solve the same problem are not equally fast, and how an algorithm's running time grows with input size is what separates a practical solution from an impractical one.

Covered, no locator on record

No informal efficiency discussion (counting statement executions, comparing two algorithms for the same problem) appears anywhere in chapters 1-13. Occurrences of the word 'efficient' in the book are incidental, not this topic. Taught in the November algorithms block.

#3.18 Undecidable Problems AP Computer Science Principles

Some yes-or-no problems have no algorithm that can always answer correctly, no matter how much time is allowed.

Covered, no locator on record

Not carried by this book at all; a conceptual, non-programming topic. Taught in the November algorithms block.

Quick lookup by hex pair

Each character's hex code has two digits. The first digit picks the row, the second picks the column; the character where they meet is what that byte represents. For example, 4D is row 4, column D: M. Going the other way, M is in row 4, column D, so its hex code is 4D.

Row = first hex digit, column = second hex digit.

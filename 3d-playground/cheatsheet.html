3D Playground Cheatsheet

Every function the playground understands, on one page.

← Back to the Studio · 3D Playground

3D Solids

Box(width, depth, height, x=0, y=0, z=0, hole=False, fill=None, align="center", center=False)

Sized along x/y/z in that order. The base sits at z -- it is not centered on z like it is on x and y, unless center=True.

Cylinder(radius, height, x=0, y=0, z=0, hole=False, fill=None, align="center", center=False)

Stands upright along z. Base sits at z, same as Box.

align="left-top" / "top" / "right-top" / "left" / "center" / "right" / "left-bottom" / "bottom" / "right-bottom"

Like CMU's align: a 9-way grid that changes what (x, y) points at. Redefined here since z is vertical, not y: "top" means farther away from you (+y), "bottom" means closer to you (-y).

center=True

Like OpenSCAD's center: also centers the shape on z, instead of sitting with its base at z.

2D Profiles

Nothing appears until you pass one to linear_extrude() -- same as Rect/Circle in CMU graphics.

Rect(left, top, width, height)
Circle(centerX, centerY, radius, segments=32)
RegularPolygon(centerX, centerY, radius, numSides, rotateAngle=0)
Polygon(x1, y1, x2, y2, x3, y3, ...)

At least 3 points.

Label(text, x, y, size=1, font="helvetiker", bold=False, italic=False)

Centered at (x, y), like CMU's Label. font: helvetiker (default, no extra load) / arial / monospace / cursive / caveat / montserrat.

Extrude

linear_extrude(profile, height, x=0, y=0, z=0, hole=False, fill=None)

Pushes a 2D profile up along z by height. Works on Rect/Circle/RegularPolygon/Polygon/Label alike.

Boolean Operations

union(*solids, hole=False, fill=None)

Everything merged into one solid.

difference(base, *subtract, hole=False, fill=None)

base with every other shape cut out of it.

intersection(*solids, hole=False, fill=None)

Only the overlap of every shape survives -- NOT "first minus the rest" (that's difference).

Transformations

translate(solid, x=0, y=0, z=0)
rotate(solid, angle, axis="z")

angle in degrees, around one named axis ("x"/"y"/"z").

rotate(solid, [rx, ry, rz])

OpenSCAD-style: all three angles at once, x applied first, then y, then z.

translate(rotate(shape, 45), x=5)

These nest like OpenSCAD's do: innermost call applies first.

Holes

A shortcut for the common "drill a hole" case, without writing difference() by hand.

hole=True

On Box / Cylinder / linear_extrude / union / difference / intersection. Every hole-marked shape is subtracted from everything else at the end. As soon as any hole exists, all non-hole top-level shapes get merged into one solid first -- reach for difference() directly if you need finer control over what subtracts from what.

Colors (preview only)

fill= never reaches the exported STL -- 3D prints have no color. It just helps you tell shapes apart while you build.

fill="red"

Any CSS/X11 color name works, not just a fixed list.

red crimson darkorange gold green cornflowerblue mediumorchid gray

Coordinate System

x, y is the flat ground plane -- the same plane you already draw on in 2D graphics. z is the new axis: straight up, out of the page.

A shape's height sits with its base AT z, not centered on it -- Box(2,2,2) sits on the ground, it doesn't straddle it.

# Semester 1 Calendar, Fall 2026
Class meets Tuesday and Thursday, 2 hours. First class Thursday, August 6. No class Thanksgiving week (Nov 23 to 27). Last class Thursday, December 10.
35 sessions total. Overlay the district calendar for PD days and any fall break; sprint boundaries can slide a session without breaking anything.

Weekly rhythm once sprints begin: Tuesday opens with the lesson (20 to 40 min), rest is studio time. Thursday is full studio time; pool-day Thursdays close each sprint. Python rung demos happen during any studio time at the checks corner.

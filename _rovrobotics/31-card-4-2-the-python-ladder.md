**Format:** Weekly self-paced homework with live demo checks | **Time:** ~30 min per week, all season | **Prerequisites:** Card 4.1

## Core Question
By winter break, everyone in the company should be able to read the float's code and write small tools. Not become a software engineer; become a person code does not scare. What is the path?

## Resource
Think Python (free online, Colab notebooks linked from the class page). The notebooks are your practice space; they are never collected or graded.

## The Rungs
One rung per week, roughly:
1. print and input: a script that asks questions and responds
2. Variables and types: numbers vs. strings and why '2' + '2' is not 4
3. Conditionals: a script that makes a decision
4. Loops: repeat, count, accumulate
5. Functions: package logic with a name, arguments, and a return
6. Lists and iteration: many values, one variable
7. Files: read a CSV line by line and pick out a value

Each rung has a tiny robot-flavored transfer task on the class page (example, rung 5: write kpa_to_depth() from Card 3.7).

## Clearing a Rung
A 90-second live demo at the machine: show your transfer task running, then modify it on request ("make it count down instead," "add a second argument"). Live modification is the whole check; anyone can display finished code, only someone who understands it can bend it on the spot.

## If You Miss a Week
The ladder does not care about the calendar. Clear rungs at your pace during studio time; ahead is fine, behind just means climb.

## Why This Matters
Rung 7 plus Cards 4.3 and 4.4 equals the complete required float data deliverable. The ladder is also the gate for joining software-heavy sprint work: teams recruit from the top rungs.
